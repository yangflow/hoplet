# Security policy

## Reporting a vulnerability

Report it privately through GitHub's private vulnerability reporting on this repository:
https://github.com/yangflow/hoplet/security/advisories/new. Do not open a public issue, discussion or pull request
for it.

Include what is affected (core, agent or web UI, and the versions), how to reproduce it, and what an attacker
gains. Do not include real tokens or session content.

## What to expect

Hoplet is maintained by one person. A report is acknowledged within about a week; a confirmed vulnerability is
fixed in a new release and disclosed in a GitHub security advisory, crediting the reporter unless they ask
otherwise. There is no bug bounty.

## Supported versions

Before 1.0, only the latest release gets security fixes. What Hoplet protects, and how, is in
[docs/threat-model.md](docs/threat-model.md).
