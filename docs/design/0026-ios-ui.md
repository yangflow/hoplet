# 0026 iOS 界面

状态：当前设计 · 更新：2026-11-08

## 范围与现状

范围：iPhone 上的页面结构、手势、颜色、图标与文案；协议客户端和推送链路不在本文。

| 状态 | 边界 |
|---|---|
| ✓ 已定稿 | 收件箱、Personal、Code、搜索、会话、审批与提问、新建、浏览目录、选模型、变更、设置、分组与归档、配对、断线、灵动岛与锁屏、通知 |
| ○ 需要后端 | 恢复归档、分组存储、浏览主机目录 |
| ○ 未绘制 | 产物查看、App 内 Face ID、标为未读、重命名 |

未绘制的状态先审核再实现。

## 原则

- 按手机的用法重新组织，不把桌面布局缩小：同一时间只做一件事，操作放在拇指够得到的底部，次要操作进菜单、长按或左右滑。
- 质感用 iOS 26 系统默认的 Liquid Glass 与标准 SwiftUI 组件，不自造外观。
- 能用状态点或图标的不用文字；必须写字时短而清楚。每个点和图标都有无障碍标签。

## 导航

底部四个标签：收件箱（数字角标是需要你的数量）· Personal · Code · 搜索。进入会话后隐藏标签栏。

| 位置 | 内容 |
|---|---|
| 左上 | 设置（头像）；子页面是返回，sheet 是关闭 |
| 右上 | 列表页：整理（仅 Personal、Code）· 新建 |

## 会话列表

- 行：单色 harness 标志 + 两行文字（标题、摘要）。没有分隔线和行尾箭头；按下时是一块圆角浅底。Code 的摘要后接机器，关闭按目录分组时接工作目录。
- 行尾只放一个标记，优先级从上到下：

| 状态 | 标记 |
|---|---|
| 断线 | 灰色 `wifi.slash` |
| 需要你 | 琥珀实心点 |
| 运行中 | 转动的 `progress.indicator` |
| 失败 | 方块 |
| 未读 | 青色小点，标题加粗 |
| 空闲 | 相对时间 |

- 手势：右滑置顶，左滑归档并显示带撤销的提示（4 秒）；长按：置顶、移到分组、归档。
- 收件箱分“需要你”和“最近”。需要你的行第二行写要做的事，右滑允许一次、左滑拒绝，点开处理 sheet；不能在列表里批“始终允许”。机器断线时这些行没有左右滑，点开直接进入会话。

### 分组与归档

- Personal、Code 都有自定义分组，也都能置顶和归档；伙伴的归档就是归档它的主会话。
- 列表顺序：自定义分组在前；Code 其余会话按工作目录分组，Personal 其余会话不分组。“按工作目录分组”可关闭，关闭后 Code 其余会话也不分组。
- 分组标题：名称 · 数量 · 右侧箭头；点击折叠，长按删除分组。删除分组只把会话移出，不删会话。折叠状态只存在本机。
- 整理菜单：新建分组 · 全部折叠 / 全部展开 · 按工作目录分组（仅 Code）· 已归档。
- 已归档是从整理菜单推入的独立页面，保留标签栏，只列当前模式；左滑或长按恢复，空时显示“没有归档的会话”。

## 会话

- 顶栏居中：标题，下面一行 harness 标志 · 机器 · 工作目录。右上：变更（仅 Code）· 更多（产物、终端（仅 Code）、分叉；置顶、归档）。
- 正文单列；工具步骤折成一行，点开 sheet；改动是文件胶囊，点开单列 diff，左右滑换文件。离开底部时右下出现回到最新。
- 输入框静止时是胶囊，书写时展开成卡片，露出模型、强度（含 Plan、Fast）、审批档位。运行中且没写字时发送键变停止；运行中发送进入排队，长按发送键是插话。
- 排队卡在输入框上方，每条可插话、编辑、撤回。

### 审批与提问

等待时面板取代输入框，答完不离开会话；可收起成带琥珀点的胶囊。审批按钮：拒绝 · 始终允许 · 允许一次。提问是编号选项加“其他回答”，选中后短暂反馈再收起。

## 配对

- 没有配对过任何机器时，App 只显示欢迎页：图标、“连接你的机器”、“在机器上运行”和命令 `hoplet pair`，底部“扫码配对”。设置里的“配对新设备”打开同一个流程。
- 流程在一个 sheet 里走完，连接中和完成时没有关闭按钮：

| 步骤 | 内容 |
|---|---|
| 扫码 | 全屏黑底取景框，下方一行提示“在机器上运行 hoplet pair”，底部“粘贴配对码” |
| 确认 | 机器图标和名字，“这台手机的名字”输入框（默认设备名，不能为空），按钮“配对” |
| 连接中 | 转圈，“正在连接 MacBook” |
| 完成 | 绿色对勾，“已配对 MacBook”，约 1 秒后自动关闭 |

- 本地就能判断的错误留在扫码页，替换提示行并触发错误震动：“不是 Hoplet 配对码”“配对码已过期，重新运行 hoplet pair”。
- 没有相机权限时，取景框换成空状态“没有相机权限”，按钮“打开设置”，仍可粘贴配对码。
- 连接失败整屏显示：

| 情况 | 标题 | 说明 | 按钮 |
|---|---|---|---|
| 连不上 | 连不上 MacBook | 确认两台设备在同一网络，或给 MacBook 配置中继 | 重试 |
| 配对码用过或被新码取代 | 配对码已失效 | 它用过了，或已生成新的。在机器上重新运行 hoplet pair | 重新扫码 |

## 断线

机器有四种连接状态：在线、重连中、断线、已吊销。路线切换和短暂抖动不显示，用户看到的仍是在线：连接断开后 2 秒内连回就不算断。超过 2 秒显示重连中，按 1、2、4、8、16 秒退避重试，约 30 秒后仍连不上显示断线；断线后每 30 秒继续重试，回到前台、网络变化或点按时立即重试。重连中除列表行尾和设置的设备行外，都按断线显示，操作要等连上。

| 位置 | 断线时 |
|---|---|
| 列表行尾 | 灰色 `wifi.slash`，优先于其他标记；收件箱角标不变。重连中不换标记，避免闪烁 |
| 会话顶栏 | 机器名前加 `wifi.slash` |
| 输入框 | 虚线描边，草稿仍可编辑，不能发送；发送键换成 `wifi.slash`，点按重新连接；重连中是转动的 `progress.indicator` |
| 审批与提问面板 | 内容照常显示，操作置灰，标题前换 `wifi.slash`，文字“连上后才能处理”；可收起，胶囊仍是琥珀点，收起后能点到输入框的重连键 |
| 设置的设备行 | 名字加状态标记：在线绿色实心，重连中转圈，断线灰色空心；点断线的行重新连接 |

已吊销的机器不能重连，只能重新配对：列表和顶栏与断线相同，发送键换成 `qrcode.viewfinder`，设备行行尾写“重新配对”，点按都打开配对流程。

## 新建

- Sheet 上方是留白，输入框贴底，靠近键盘。Personal 第一行是伙伴名字。
- 输入框下一行可横向滚动的按钮：工作目录（仅 Code）· 机器 · 模型 · 强度 · 审批档位；选模型就是选 harness。
- 机器菜单每项是名字加状态点：在线绿色实心，未连接灰色空心，当前项打勾。选中离线机器时，按钮换 `wifi.slash`，输入框虚线描边，不能发送，菜单里有重新连接。
- 工作目录菜单列这台机器最近用过的目录，末项“浏览目录”：一层一屏地进入，右上新建目录，底部“选择此目录”，根层可切机器。

## 变更

半屏 sheet，可拉满。右上切范围：会话累计 / 未提交的改动 / 分支改动 / 某个提交。每个仓库一节（名称 · 分支 · 增删数），文件行：M / A / D · 文件名 · 目录 · 增删数。非 git 目录、没有改动、读取失败各有一行状态。

## 灵动岛与锁屏

全 App 只占一个 Live Activity，显示最要紧的会话：需要你的优先，其余在状态标记旁写 +N。

| 形态 | 内容 |
|---|---|
| 紧凑 | 左：harness 或伙伴标志；右：状态标记 |
| 最小 | 状态标记 |
| 展开 | 标志、标题、+N、状态标记；下面是摘要、命令（等宽）或问题，最多两行；审批时加按钮 |
| 锁屏 | 标志、标题、+N、状态标记一行；其余与展开相同 |

- 状态标记与列表行尾相同：运行中转动的 `progress.indicator`，需要你琥珀实心点。
- 审批按钮：拒绝 · 允许一次。按下后活动回到运行中。
- 提问不在灵动岛或锁屏上回答，点开进入会话。

## 通知

- 只在需要你或出错时响；任务完成默认不打扰。设置里的“需要你时通知”是总开关。
- 标题是会话名，正文是要做的事：审批写“运行 + 命令”，提问写问题，出错写错误摘要。
- 审批通知长按：✓ 允许一次 · ✕ 拒绝。提问和出错没有操作。点通知进入对应会话。
- 内容无法解密时只显示“有会话需要你”，不露任何会话内容。

### 锁屏上的审批

允许一次要先通过 Face ID，拒绝不用。“始终允许”不出现在灵动岛、锁屏和通知上。

## 颜色

界面控件中性（跟随文字色）。其余颜色只用在：

| 颜色 | 浅色 / 深色 | 只用于 |
|---|---|---|
| 青 | #066A70 / #3CC4C9 | 允许一次、可发送时的发送键、右滑允许、未读点 |
| 琥珀 | #B5651A / #F0A35B | 需要你 |
| 红 | 系统红 | 拒绝、角标、删除行 |
| 绿 | 系统绿 | 在线点、新增行、开关、配对完成 |

## 图标与文案

- 图标用 SF Symbols，不用 Lucide；harness 标志单色、跟随文字色。
- 称“你”，不加“请”，不用感叹号与 emoji；按钮以动词开头、2–4 个字；中英文之间加空格；写 Hoplet、Claude Code、Codex、Hermes。词表与桌面相同：会话、伙伴、工作目录、变更、产物、审批、插话、排队、分叉、需要你、断线（不说对话、Bot、项目、轮）。

## 需要的后端

| 能力 | 约定 |
|---|---|
| 恢复归档 | 新增方法清除归档时间；harness 下次发送时再启动 |
| 分组 | 分组按模式由守护进程保存，所有客户端一致；空分组也保留 |
| 浏览主机目录 | 新增方法列出某台机器某路径的子目录，并能新建目录；不依赖已有会话 |

桌面暂不显示分组；要显示时先绘制审核。
